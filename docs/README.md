# 顶飞翼项目资料

- `protocols/车载A-BOX设备对接协议-20260821.md`：当前公共平台业务协议，定义 `top_flying_wing`、MQTT 控制、主动状态、故障和安全停止语义。
- `protocols/顶飞翼A-BOX内部运维协议-1.0.md`：OTA 平台与顶飞翼固件之间的设备信息、日志、重启、VID/MQTT 配置和 Boot V2 OTA 协议。
- `vendor/四通道 两通道大功率控制器说明书(MS-04-25A-A).pdf`：同步控制器产品说明书。
- `vendor/CAN2.0 扩展帧通讯协议1.2.pdf`：A-BOX 与同步控制器之间的厂家通信协议。

公共业务对接方只依赖《车载 A-BOX 设备对接协议》中的 MQTT 业务语义；内部运维协议只供受控 OTA 平台使用。`vendor/` 资料用于设备端实现和硬件联调，其中的底层通信细节不属于平台接口。
