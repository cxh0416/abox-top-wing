# 2026-06-15 A-BOX 新板引脚核对（内部实现）

内部资料，不作为业务对接协议对外交付。依据 `E:/1_work/A-BOX/SCH_AirprotTbox_2026-06-15.pdf` 的 MCU、隔离输入、电源输出和 CAN 收发器页核对。

## 隔离输入

| 输入网络 | 连接器 | MCU |
| --- | --- | --- |
| `IO_IN1` | `B4` | `PC3` |
| `IO_IN2` | `B5` | `PC2` |
| `IO_IN3` | `B6` | `PC1` |
| `IO_IN4` | `B7` | `PC0` |
| `IO_IN5` | `B8` | `PA7` |
| `IO_IN6` | `B9` | `PA6` |
| `IO_IN7` | `B10` | `PA5` |
| `IO_IN8` | `B11` | `PA4` |

防夹条使用常开无源干接点，一端接外部连接器 `B8/IO_IN5`，另一端接 `PGND`，经 `U16` 光耦后进入 `PA7`。`B8` 不是 MCU 引脚的直连端：触点断开时 MCU 侧由板上电阻网络拉低；挤压使触点闭合、光耦导通，`PA7` 变高。因此 `PA7` 配置为无内部上下拉输入，软件按高电平受压判断。

## CAN

| 功能 | MCU | 收发器待机 |
| --- | --- | --- |
| CAN1/VCU | `PA11` RX、`PA12` TX | `PB15` |
| CAN2/遥控手柄 | `PB12` RX、`PB13` TX | `PB14` |

## 输出

| 功能 | MCU |
| --- | --- |
| `PWR12V_OUT1` | `PA0` |
| `PWR12V_OUT2` | `PA1` |
| `PWR12V_OUT3` | `PA2` |
| 继电器输出 | `PC4` |
| `COMM` 指示 | `PB0` |
| `LINK` 指示 | `PB1` |
| `WORK` 指示 | `PB2` |

产品代码将 PA0 第一路电源输出用于防夹条和超声波共用的报警供电。PA1、PA2、PB0、PB1、PB2 的原旧板定义已同步纠正，避免把 LED 网络误配置成电源输出。
